# Ivy Lee Planner on the web

Add tasks and notes from a computer; the phone app takes them in the next
time it opens. A plain static page with no server and no AI: it talks only to
Google sign-in and Google Drive (the app's hidden folder).

This repository holds only the published copy of the page. Its source and
how it works are in the app's repository (`web/` and `web/README.md`); copy
changes over from there.
